# Compatibility and verification

A metapackage: it contains no code and works wherever the packages it installs work.

**Minimum: Magento Open Source 2.4.4** with PHP 8.1, through `commercekings/module-consent-notification` and
`commercekings/module-consent-vanilla`. Their compatibility files list what was verified:
[consent bridge](https://github.com/commercekings/module-consent-notification/blob/main/COMPATIBILITY.md) ·
[cookie banner](https://github.com/commercekings/module-consent-vanilla/blob/main/COMPATIBILITY.md).
